# SakthiAI Generative Media Research Intake

Status: **RESEARCH EVIDENCE — NOT PRODUCTION PROVIDER APPROVAL**

This directory is the governed landing zone for owner-supplied Gemini scheduled-task research concerning generative media. GitHub remains the canonical SakthiAI source repository; the research inputs remain evidence/provenance, not executable dependencies.

## Source handling

The owner-supplied research represents approximately one month of scheduled Gemini collection. It must be preserved and reused rather than restarted. No new Gemini or ChatGPT schedule is required by this repository.

Historical material is not automatically current truth. Provider/model/API/pricing/licensing/privacy/retention/regional claims require direct primary-source verification and a `lastVerifiedDate` before they may be represented as current. Unresolved claims remain `UNKNOWN`, `HISTORICAL`, or `REQUIRES_PROVIDER_VALIDATION`.

## Product routing

Research is routed by capability rather than vendor:

- Web/PWA: capability discovery, studio UX, job status, history, provenance and cost/consent controls.
- Server/runtime: provider-neutral capability contracts, asynchronous job lifecycle, retries/idempotency, observability and adapters.
- Mobile: reuse the same provider-neutral API contracts later; this directory does not claim a mobile implementation exists.
- Production: no provider is enabled, purchased, or made mandatory by research ingestion.

## Canonical capability families

See `capability-registry.json`. Stable IDs intentionally survive provider/model churn.

## Evidence policy

1. Keep consumer UI availability separate from first-party API availability.
2. Keep marketing product names separate from exact API model IDs.
3. Keep subscription/credit pricing separate from API billing.
4. Never infer Tamil quality from language availability; SakthiAI quality requires its own evaluation evidence.
5. Voice clone/avatar/digital-twin capabilities require consent, identity, revocation and disclosure controls.
6. Local/open models require repository, code/weight/dependency licenses, version, maintenance and hardware evidence before production consideration.
7. Research-only records must never be surfaced as shipped capabilities.

## Current historical baseline

The recovered continuation ledger identifies a broad provider-neutral scope including image generation/editing/upscaling, text/image/video generation, reference conditioning, video extension/editing/assembly, avatars/talking photos/digital twins, TTS/voice design/cloning/speech-to-speech, dubbing/translation/lip-sync/captions, music/SFX/audio cleanup, scripts/storyboards, Tamil creator evaluation and social-content pipelines.

The same ledger explicitly quarantines unsupported or stale provider assertions and records that no production media provider adapter or generated demonstration media was established by the research task itself.

## Release rule

This directory can inform design and implementation. It cannot by itself change SakthiAI readiness, activate a provider, authorize paid usage, or establish production quality.
